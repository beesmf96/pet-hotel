# Second DRY sweep

## Asked
Run `/dry-sweep` again after the design review. The user approved every
Extract and every Ask finding, plus a fix for a suspected bug.

## Done
- **Backend:**
  - `Booking::isPending()` replaces 9 copies of `status === 'pending'`.
  - A `pending()` scope replaces 3 copies of `where('status', 'pending')`
    (expiry command, admin widget, owner nav badge).
  - `Dates::TIME`, `MOMENT` and `SHORT_TIME` replace the hand-typed time
    formats in `PetHotelPolicy` and the owner booking table and pop-up.
    `MOMENT` is the PHP source for the JS `formatDateTime()`.
- **Frontend:**
  - AppLayout's header now sizes the `<h1>`, like `leading-tight`, so 9 pages
    write a plain `<h1>`.
  - A new `PageSubtitle` component takes the 3 header subtitles.
  - A new `DetailRow` component takes the label/value rows on booking detail
    and confirmation. Long values now wrap right-aligned on both pages,
    which settles a note from the design review.
  - The calendar legend comes from one list.
- Tests: `BookingPendingTest`, plus Vitest specs for `DetailRow`,
  `PageSubtitle` and the header sizing.

## Not done
- **The suspected bug was not real.** The owner pop-up's "Requested" time
  already uses `display_timezone`; the scan had cut the line short. The
  existing test confirms Kuala Lumpur time.
- **Left by the rules:** 2-copy repeats (the "or" divider, "Save changes",
  `handleSearch`), the `'Y-m'` month keys, and the status writes in
  `confirm()`, `cancel()` and on create.
