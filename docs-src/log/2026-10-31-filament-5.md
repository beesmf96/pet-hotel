# Filament 5

## Asked
"yep filament 5 please", after the dependency check and the minor updates.

## Done
- Dependencies: `filament/filament` 5.11 and `livewire/livewire` 4.4. Filament's
  own published assets under `public/` changed with them.
- `vendor/bin/filament-v5` found nothing to rewrite in `app/`. `filament/upgrade`
  was installed for that run and removed in this PR, so it has no intake entry.
- Docs: the version in `CLAUDE.md`, `local-setup.md` and the PID.

## Not done
- The script suggests a plain `composer update`. That was not run, because it
  would also take Guzzle to 8 and phpseclib to 4 (see
  `2026-10-31-minor-dependency-updates.md`). Only `filament/*` and Livewire moved.
- PHPUnit 13, Vitest 5, jsdom 30, concurrently 10 and the Guzzle majors.

## Produced
- ADR: none
- Knowledge: none
- Intake: none

## Verified
- `composer test`: 552 passed. Coverage could not be measured in the local
  container (no pcov); CI measures it. `vendor/bin/pint --test`: pass.
- `bun run test`: 342 passed. `bun run lint`: 0 errors, the same 5 old warnings.
- `composer audit`: no advisories.
- Headless Chromium on the local Docker stack (Postgres): every admin and owner
  page returned 200 with no console, CSP or network errors, and the panel theme
  looks the same. The Attach pop-up lists users, and a photo uploaded through
  the admin form on the local disk.
- Not checked: an upload to the real bucket on Laravel Cloud. Livewire 4's upload
  route has a hashed path (`/livewire-{hash}/upload-file`).
